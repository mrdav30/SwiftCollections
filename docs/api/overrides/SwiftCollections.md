SwiftCollections provides specialized lists, hash tables, buckets, handles,
packed sets, sparse containers, state-backed serialization, and shared query
volume types for performance-sensitive .NET applications.

The package is engine-agnostic. Unity projects should use the maintained
[SwiftCollections-Unity packages](https://github.com/mrdav30/SwiftCollections-Unity)
for Unity-serializable authoring adapters, `Bounds` conversion, GameObject
pooling, and samples.
