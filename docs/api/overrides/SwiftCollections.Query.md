The query namespace contains BVH, spatial hash, and octree structures plus their
floating-point volume contracts. Install the matching
`SwiftCollections.FixedMathSharp` companion for fixed-point volumes and query
structures backed by
[FixedMathSharp](https://github.com/mrdav30/FixedMathSharp).

Unity projects can add the matching
[SwiftCollections-Unity FixedMathSharp companion](https://github.com/mrdav30/SwiftCollections-Unity)
for explicit conversion from Unity `Bounds`.
